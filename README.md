### ⚡ LLM Quantization & Efficient Inference

### 👁 Grounded VLM with CV Tool Verification

Multimodal visual verification system based on **Qwen2.5-VL** with support for text answers, bounding boxes and structured JSON.

Combined VLM outputs with **object detection, OCR and classical CV tools** for result verification and improved grounding reliability.
